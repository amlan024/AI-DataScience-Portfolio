# AI + Data Science Portfolio

A personal portfolio website showcasing my skills, projects, and an AI + Data Science based Waste Water Management System.

## Project Overview

This project combines:

- HTML/CSS/JavaScript
- Python
- Data Science
- Machine Learning
- Flask
- MySQL
- Data Visualization
- GitHub

The main project is a Waste Water Management System that analyzes wastewater quality parameters and predicts treatment efficiency using Machine Learning.

## Waste Water Management System

The system uses wastewater quality parameters such as:

- pH
- Turbidity
- Temperature
- BOD
- COD
- TSS
- Dissolved Oxygen

The target variable is:

- Treatment Efficiency
